# PRD: Сайт ТОО «N-VECTOR Consulting Services»

**Статус:** V1 реализован (статический сайт готов), подключение к Google Таблице и публикация — в процессе.
**Владелец:** Нагима Набиева, основатель и генеральный директор N-VECTOR.

---

## 1. Контекст и цель

У компании уже есть сайт n-vector.net (статический HTML/CSS/JS, развёрнутый через Netlify). Текущий проект — **отдельный, самостоятельный сайт**, не развитие существующей версии: разрабатывается с нуля, с новой структурой и новым функционалом для самостоятельного пополнения контента.

**Цель:** публично доступный сайт компании, который можно пополнять новой информацией (команда, проекты, мероприятия, программы поддержки) без участия разработчика — через кнопку «+».

## 3. Пользователи и права доступа

| Роль | Доступ |
|---|---|
| Нагима (админ) | Полный доступ: добавление контента + модерация (публикация записей) |
| Несколько сотрудников | Могут добавлять записи через кнопку «+» (команда, проекты, мероприятия, программы) |
| Посетители сайта | Только просмотр опубликованного контента |

Кнопка «+» технически доступна любому посетителю страницы (отдельной системы входа нет), но **новые записи не публикуются автоматически** — см. раздел 5.

## 4. Функциональные требования

### 4.1 Добавление контента («+»)
- На страницах «Команда», «Проекты», «Мероприятия», «Программы поддержки» есть кнопка «+» (плавающая и в шапке раздела), открывающая форму.
- Форма отправляет данные напрямую в Google Таблицу, которая выступает базой данных сайта.
- Каждый раздел — отдельный лист в таблице, со своим набором полей.

### 4.2 Модель данных

**team** (Команда): `id, name, role, bio, tags, photo, email, status` (`tags` — компетенции через запятую, `photo` — ссылка на фото)
**projects** (Проекты): `id, name, tag, description, year, link, status`
**events** (Мероприятия): `id, title, date, location, description, link, status`
**programs** (Программы поддержки): `id, type, name, description, deadline, link, status`

`status` = `pending` (на модерации) или `published` (опубликовано).
`type` для программ: Конкурс / Обучение / Инкубация-Акселерация / Финансирование.

### 4.3 Модерация
- Новая запись с сайта всегда попадает со статусом `pending` и не отображается публично.
- Публикация — вручную: смена значения `status` на `published` прямо в Google Таблице.
- Причина: доступ к «+» есть у нескольких сотрудников, а не только у админа — модерация защищает сайт от случайных/незавершённых записей.
- Опционально предусмотрена возможность отключить модерацию (мгновенная публикация) — изменением одной строки в коде бэкенда.

### 4.4 Отображение данных
- Сайт загружает только записи со `status = published`.
- Если бэкенд (Google Таблица) ещё не подключён или недоступен — сайт показывает резервные локальные данные, чтобы не оставаться пустым.

### 4.5 Программы поддержки
- Каждая запись — название, тип, описание, (опционально) дедлайн подачи заявки, и обязательная ссылка на официальный сайт программы.
- Стартовый набор данных включает реальные действующие программы (QazInnovations, Astana Hub) с проверенными ссылками.

## 5. Технические требования

| Компонент | Решение |
|---|---|
| Фронтенд | Статические HTML/CSS/JS, без сборки, 5 страниц |
| Хранилище данных | Google Таблицы (4 листа по числу разделов) |
| API-слой | Google Apps Script (Web App): `doGet` отдаёт JSON по листу, `doPost` добавляет запись со статусом `pending` |
| Локальный резерв | JSON-файлы в `data/`, используются, пока Google-бэкенд не подключён или недоступен |
| Хостинг | Netlify (drag-and-drop), как и для текущего сайта |
| Домен | n-vector.net (решение по домену — отдельно, т.к. сайт отдельный от текущей версии) |

**Почему не публикация через встроенный инструмент Claude:** такие страницы работают в песочнице без доступа к внешним API, поэтому Google Таблицы как бэкенд там подключить нельзя. Отсюда — обычный файловый проект для самостоятельного хостинга.

## 6. Требования к дизайну

- Стиль: классический, светлый, технологичный.
- Фирменная сине-бирюзовая гамма логотипа N-VECTOR (два треугольника с градиентом); логотип — в шапке, подвале и иконке вкладки. Белые карточки со скруглением на светло-голубом фоне; схематичная диаграмма на главной.
- Шрифты: Archivo (заголовки), IBM Plex Sans (текст), IBM Plex Mono (технические обозначения).
- Адаптивность под мобильные устройства, видимый фокус для клавиатуры. Только светлая тема (тёмная убрана по решению владельца).
- Главная: «Что мы делаем» (3 услуги), блок «Ключевой проект компании» (SeedMaster Systems), блок команды с фото.
