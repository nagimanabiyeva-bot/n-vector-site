# Подключение Google Таблицы к сайту

Пока таблица не подключена, сайт показывает резервные данные из `data/fallback.js`, а кнопка «+» сообщает, что запись не отправлена.

## 1. Создайте таблицу и скрипт

1. Создайте новую Google Таблицу, например «N-VECTOR — сайт».
2. В меню: **Расширения → Apps Script**.
3. Удалите содержимое `Код.gs` и вставьте целиком файл `apps-script/Code.gs`. Сохраните (Ctrl+S).
4. В выпадающем списке функций выберите **setup** и нажмите **Выполнить**. Google попросит разрешения на доступ к таблице — подтвердите.
   Появятся 4 листа: `team`, `projects`, `events`, `programs` со строкой заголовков.

## 2. Разверните веб-приложение

1. **Развернуть → Новое развертывание** → тип **Веб-приложение**.
2. «Выполнять от имени»: **Я**.
3. «У кого есть доступ»: **Все** (иначе сайт не сможет читать данные).
4. Нажмите **Развернуть** и скопируйте ссылку вида `https://script.google.com/macros/s/…/exec`.

## 3. Впишите ссылку в сайт

Откройте `js/main.js` и вставьте ссылку:

```js
const CONFIG = Object.freeze({
  API_URL: 'https://script.google.com/macros/s/…/exec',
  ...
});
```

Проверка: откройте в браузере `ссылка?sheet=programs` — должен вернуться JSON вида `{"ok":true,"data":[...]}`.

## 4. Перенесите стартовые данные

Скопируйте записи из `data/fallback.js` в соответствующие листы (порядок столбцов — как в заголовках) и поставьте в столбце `status` значение `published`.
Записи с пометкой «Образец» замените реальными.

Лист `team`: в столбце `tags` компетенции перечисляются через запятую; в `photo` — ссылка на фото
(`https://…` или путь к файлу сайта, например `img/team/nagima-nabiyeva.jpg`). Пустое `photo` — на карточке будут инициалы.

Ключевой проект SeedMaster Systems оформлен на страницах вручную, в лист `projects` его добавлять не нужно —
туда идут только дополнительные проекты (блок «Другие проекты» появится, когда в листе будет хотя бы одна опубликованная запись).

## Модерация

- Записи, отправленные через «+», попадают в таблицу со статусом `pending` и на сайте не видны.
- Чтобы опубликовать — поменяйте `pending` на `published` в столбце `status`.
- Чтобы отключить модерацию, в `Code.gs` поменяйте `const MODERATION = true;` на `false`
  и сделайте **Развернуть → Управление развертываниями → Изменить → Новая версия**.

## Важно

- После **любого** изменения `Code.gs` нужно выпускать новую версию развертывания, иначе сайт будет работать со старым кодом.
- Даты в таблице храните в формате `ГГГГ-ММ-ДД` (например, `2026-03-15`).
- Тип программы — строго одно из: `Конкурс`, `Обучение`, `Инкубация-Акселерация`, `Финансирование`.

## Публикация на Netlify

Перетащите всю папку проекта (с `index.html` в корне) на https://app.netlify.com/drop.
