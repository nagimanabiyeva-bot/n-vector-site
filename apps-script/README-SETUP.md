# Подключение Google Таблицы и админ-панели

Сайт состоит из двух частей:

- **пользовательская версия** (`index.html` и остальные страницы) — только просмотр опубликованных записей;
- **админ-панель** (`admin.html`) — добавление, редактирование, публикация и удаление записей кнопками, с переводами RU / EN / KZ.

Пока таблица не подключена, сайт показывает данные из `data/fallback.js`, а админ-панель работает в **демо-режиме**
(правки хранятся в браузере; их можно скачать файлом `fallback.js` и заменить им `data/fallback.js`).

## 1. Создайте таблицу и скрипт

1. Создайте новую Google Таблицу, например «N-VECTOR — сайт».
2. В меню: **Расширения → Apps Script**.
3. Удалите содержимое `Код.gs` и вставьте целиком файл `apps-script/Code.gs`. Сохраните (Ctrl+S).
4. В выпадающем списке функций выберите **setup** и нажмите **Выполнить**. Google попросит разрешения на доступ к таблице — подтвердите.
   Появятся 3 листа: `team`, `projects`, `events` со всеми столбцами, включая переводы (`name_en`, `bio_kz` и т. д.).
   Если листы уже были — `setup` только допишет недостающие столбцы, данные не тронет.

## 2. Задайте ключ администратора

Ключ — это пароль для входа в админ-панель. В коде его нет, он хранится в настройках скрипта:

1. В редакторе Apps Script: **Настройки проекта** (шестерёнка слева) → **Свойства скрипта** → **Добавить свойство**.
2. Название: `ADMIN_KEY`, значение — длинный случайный пароль (**не короче 12 символов**, лучше 20+).
3. Сохраните. Передавайте ключ только тем сотрудникам, кому нужен доступ к админке. Чтобы отозвать доступ — смените значение.

## 3. Разверните веб-приложение

1. **Развернуть → Новое развертывание** → тип **Веб-приложение**.
2. «Выполнять от имени»: **Я**.
3. «У кого есть доступ»: **Все** (сайт читает опубликованные записи без входа; изменения всё равно требуют ключ).
4. Нажмите **Развернуть** и скопируйте ссылку вида `https://script.google.com/macros/s/…/exec`.

## 4. Впишите ссылку в сайт

Откройте `js/shared.js` и вставьте ссылку:

```js
const CONFIG = Object.freeze({
  API_URL: 'https://script.google.com/macros/s/…/exec',
  ...
});
```

Проверка: откройте в браузере `ссылка?sheet=team` — должен вернуться JSON вида `{"ok":true,"data":[...]}`.

## 5. Перенесите данные

Самый простой способ: до подключения таблицы откройте `admin.html` в демо-режиме, внесите всё нужное, затем
после подключения добавьте записи в админке уже по ключу. Можно и вручную: скопируйте записи из `data/fallback.js`
в листы и поставьте в столбце `status` значение `published`.

## Работа в админ-панели

- Откройте `admin.html` (на сайте ссылки на неё нет — адрес знают только администраторы) и введите ключ.
- Вкладки сверху — разделы сайта. У каждой записи кнопки **Изменить**, **Опубликовать / Скрыть с сайта**, **Удалить**
  (удаление — двойным нажатием, чтобы не удалить случайно).
- **+ Добавить** открывает форму. Тексты заполняются на вкладках **RU / EN / KZ**; пустой перевод — на сайте покажется русский текст.
  Переключатель «Опубликовано на сайте» решает, увидят ли запись посетители (иначе это черновик).
- Метки `EN ✓ / KZ —` в списке показывают, переведена ли запись.
- Вход запоминается до закрытия вкладки; кнопка **Выйти** забывает ключ сразу.

## Важно

- После **любого** изменения `Code.gs` нужно выпускать новую версию развертывания
  (**Развернуть → Управление развертываниями → Изменить → Новая версия**), иначе будет работать старый код.
- Даты — в формате `ГГГГ-ММ-ДД` (в админке выбираются календарём).
- Фото участника: ссылка `https://…` или путь к файлу сайта, например `img/team/nagima-nabiyeva.jpg`.
- Ключевой проект SeedMaster Systems оформлен на страницах вручную; в лист `projects` идут только дополнительные проекты
  (блок «Другие проекты» появится, когда будет хотя бы одна опубликованная запись).
