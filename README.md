# Сайт ТОО «N-VECTOR Consulting Services»

Статический сайт (HTML/CSS/JS, без сборки) из двух частей: пользовательская версия для просмотра и админ-панель
для управления контентом. База данных — Google Таблица через Google Apps Script.

## Возможности

- **Пользовательская версия** (`index.html`, `team.html`, `projects.html`, `events.html`, `contacts.html`) — только просмотр опубликованных записей.
- **Админ-панель** ([admin.html](admin.html)) — вход по ключу администратора; кнопками добавлять, редактировать, публиковать / скрывать и удалять записи команды, проектов и мероприятий; тексты записей на RU / EN / KZ; поиск и фильтр «опубликованные / черновики». Оформление как у сайта (верхняя полоса, шапка, подвал), интерфейс на трёх языках — словари [data/i18n/admin-*.js](data/i18n/), мобильная версия. Логика — [js/admin.js](js/admin.js), данные — [js/admin-store.js](js/admin-store.js).
- **Демо-режим админки** (пока таблица не подключена): правки хранятся в браузере, видны в предпросмотре сайта (`?preview=1`) и выгружаются готовым файлом `fallback.js`.
- Три языка: EN, RU, KZ — переключатель в правом верхнем углу; выбор запоминается, ссылка `?lang=en|ru|kz` открывает нужный язык. Тексты — в [data/i18n/](data/i18n/), логика — [js/i18n.js](js/i18n.js). Записи переводятся полями с суффиксом `_en` / `_kz` (например, `bio_en`).
- Web- и mobile-режимы: на широком экране — меню в строку; на телефонах и планшетах (до 1120 px) — «бургер» с меню на весь экран, крупные кнопки под палец; админка тоже адаптирована под телефон.
- Деловой дизайн: тёмная верхняя полоса с переключателем языков, белая шапка с меню и кнопкой «Связаться», первый экран с фото на всю ширину, тёмные карточки достижений, сетка услуг, тёмный блок связи и бежевый подвал. Цвета — графитово-синий `#262a36`, белый и бежевый `#cfc7bc`; шрифты Fira Sans и Montserrat.
- Фото сцены (`img/scene/`) и проекта разнесены по разделам: фон первого экрана, иконки услуг, шапки страниц, тёмный блок.
- Сдержанное движение по наведению: карточки слегка наклоняются и приподнимаются, кнопки «притягиваются» к курсору, фото смещаются за мышью ([js/motion.js](js/motion.js)).
