# Сайт ТОО «N-VECTOR Consulting Services»

Статический сайт (HTML/CSS/JS, без сборки) с пополнением контента через кнопку «+» и Google Таблицей в роли базы данных.

## Возможности

- Три языка: EN, RU, KZ — переключатель в правом верхнем углу; выбор запоминается, ссылка `?lang=en|ru|kz` открывает нужный язык. Тексты — в [data/i18n/](data/i18n/), логика — [js/i18n.js](js/i18n.js). Записи из таблицы переводятся полями с суффиксом `_en` / `_kz` (например, `bio_en`).
- Web- и mobile-режимы: на широком экране — меню в строку; на телефонах и планшетах (до 1120 px) — «бургер» с меню на весь экран, форма «+» открывается шторкой снизу, крупные кнопки под палец.

- Тёмная технологичная тема: «печатная плата» на фоне, стеклянные панели, бирюзовое свечение.
- Тематическая картинка разрезана на элементы (`img/scene/`: голограмма, мониторы, микросхема с командой, золотой чип, сервер, робот, плата), которые разнесены по разделам и шапкам страниц.
- Движение по наведению: наклон карточек за курсором с бликом, «магнитные» кнопки и метки, параллакс первого экрана ([js/motion.js](js/motion.js)).
- Разделы: о компании, команда, проекты (ключевой — SeedMaster Systems), мероприятия, программы поддержки, контакты.
- Кнопка «+» отправляет записи в Google Таблицу на модерацию.

- Требования: [PRD.md](PRD.md)
- Подключение Google Таблицы: [apps-script/README-SETUP.md](apps-script/README-SETUP.md)
